This is a website about Keru, an experimental GUI library for Rust.

Keru is still under development and is currently only available under the GPLv3 license. This might change in the future, though.

If you would like to try the library, the best way to get started is to clone the repository and explore the examples . There are three heavily commented examples that act as a tutorial: 01_intro.rs , 02_dynamic.rs , 03_components.rs .
