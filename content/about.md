<p>This is a website about <b>Keru</b>, an experimental GUI library for Rust.</p>

<p>Keru is still under development and is currently only available under the GPLv3 license. This might change in the future, though.</p>

<p>
If you would like to try the library, the best way to get started is to clone the 
<a href="https://github.com/kekelp/keru"> repository </a>
and explore the 
<a href="https://github.com/kekelp/keru/tree/master/examples"> examples </a>.
There are three heavily commented examples that act as a tutorial:
<a href="https://github.com/kekelp/keru/blob/master/examples/01_intro.rs"> 01_intro.rs </a>,
<a href="https://github.com/kekelp/keru/blob/master/examples/02_dynamic.rs"> 02_dynamic.rs </a>,
<a href="https://github.com/kekelp/keru/blob/master/examples/03_components.rs"> 03_components.rs </a>.
</p>
